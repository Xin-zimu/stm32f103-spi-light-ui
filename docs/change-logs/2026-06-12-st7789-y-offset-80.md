# ST7789 纵向偏移调整为 80

日期：2026-06-12

## 修改目标

针对背光亮但不显示或显示区域纵向错位的 240x240 ST7789 模块，把显存纵向起始
偏移调整为常见的 80 行。

## 修改前行为

驱动使用 `ST7789_Y_OFFSET = 0U`，地址窗口直接从 ST7789 显存第 0 行开始。对于
可视区域映射到显存第 80 行的模块，像素可能写到不可见区域。

## 修改后行为

驱动使用 `ST7789_Y_OFFSET = 80U`，所有可视区 Y 坐标在发送 RASET 命令前增加
80，使 240x240 图像写入该模块的实际可视显存区域。

## 逻辑变化范围

- 仅把 `ST7789_Y_OFFSET` 从 `0U` 改为 `80U`。
- SPI 引脚、方向、颜色格式、初始化命令和动画数据保持不变。

## 涉及文件

- `User/bsp_st7789.c`
- `docs/change-logs/2026-06-12-st7789-y-offset-80.md`

## 接口与兼容性

公开函数接口不变。该设置适用于显存可视区域从第 80 行开始的 240x240 ST7789
模块；如果实物模块实际要求 0 行偏移，应恢复为 `0U`。
