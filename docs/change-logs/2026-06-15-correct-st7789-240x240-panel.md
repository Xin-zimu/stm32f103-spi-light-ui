# 纠正 ST7789 240x240 面板配置

日期：2026-06-15

## 修改目标

根据实屏不对称测试图纠正面板尺寸判断，将驱动从错误的 240x320 恢复为
实物标称和实测一致的 240x240，并保留已经验证正确的 Y 偏移 0 和 SPI Mode 3。

## 修改前行为

驱动把可见高度配置为 320。测试图顶部标记位于第 8 至 55 行，可以正常显示；
底部标记位于第 264 至 311 行，超出实物 0 至 239 行可视区，因此不可见。
中下方红色竖线与可视区部分重叠，所以屏幕下方只看到一段红色。

## 修改后行为

驱动使用 240x240 地址窗口，Y 偏移保持 0。方向测试图的全部四角标记、色块、
中心十字和灰阶都重新布局到第 0 至 239 行内。

## 逻辑变化范围

- `ST7789_HEIGHT` 从 320 改回 240。
- `ST7789_Y_OFFSET` 保持 0，SPI Mode 3 保持不变。
- 底部四角、色块、中心十字和灰阶坐标压缩到 240 行范围。
- 清屏和矩形裁剪说明改为 240x240，单帧像素数据量改为 115200 字节。
- README、诊断说明和学习文档纠正此前的 240x320 误判。
- 在旧变更记录中增加后续纠正提示，保留完整排障过程。

公开函数接口、接线和 SPI 配置不变。地址窗口调整为 X=0 至 239、
Y=0 至 239，仅适用于本次实测确认的 240x240、Y 偏移 0 面板。
