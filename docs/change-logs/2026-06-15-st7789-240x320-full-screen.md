# ST7789 240x320 全屏适配

日期：2026-06-15

## 修改目标

根据逻辑分析仪和实屏现象，把当前 ST7789 纯色测试从 240x240 可见区域
调整为实际的 240x320 全屏区域，消除约四分之一高度的花屏。

## 修改前行为

驱动按 240x240 写入，并在所有 Y 坐标上增加 80 行偏移。对于实际
240x320 面板，每次纯色刷新只覆盖 57600 个像素，其余 80 行保留随机显存内容。
SPI Mode 已由用户实测设置为 Mode 3。

## 修改后行为

驱动从显存第 0 行开始写入 240x320 地址窗口，每次纯色刷新覆盖全部
76800 个像素。SPI Mode 3 保持不变。

## 逻辑变化范围

- `ST7789_HEIGHT` 从 240 改为 320。
- `ST7789_Y_OFFSET` 从 80 改为 0。
- 保留 `ST7789_SPI_MODE = 3U`。
- 同步更新驱动中的尺寸、显存占用和 SPI 模式说明，不修改初始化命令及引脚配置。
