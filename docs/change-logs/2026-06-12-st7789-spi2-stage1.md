# ST7789 SPI2 阶段1点屏

日期：2026-06-12

## 修改目标

把当前 GPIOA 软件 SPI 诊断程序改为用户指定的 GPIOB 硬件 SPI2 接线，
完成 ST7789 240x240 屏幕的阶段 1 点屏、背光控制和纯色循环测试。

## 修改前行为

当前最小固件通过 PA5、PA7、PA3、PA4 软件模拟 SPI，并假定背光直接连接
3.3V。驱动没有 PB12 背光控制，也没有使用 PB13/PB15 的 SPI2 复用功能。
Keil 工程只包含 GPIO 和 RCC 标准库文件，没有编译 SPI 与 delay 模块。

## 修改后行为

PB13 和 PB15 作为 SPI2 SCK、MOSI，PB10、PB14、PB12 分别控制 RES、DC、
BLK。ST7789 使用 Mode 0、8 位、MSB First、软件 NSS、单线发送和约
4.5 MHz 时钟。初始化完成后先清黑屏再打开背光，主循环每 500 ms 依次
显示黑、红、绿、蓝。

## 逻辑变化范围

- 把显示总线从 GPIOA 软件 SPI 改为 GPIOB 硬件 SPI2。
- 新增 PB12 背光开关，并在初始化清黑屏后打开背光。
- 新增命令、8 位数据、16 位数据和 240x240 地址窗口写入接口。
- 使用 RGB565 流式清屏，不申请全屏缓冲区和动态内存。
- 默认采用 X 偏移 0、Y 偏移 80，并允许通过头文件宏调整。
- 主程序删除状态恢复诊断循环，改为阶段 1 黑红绿蓝纯色循环。
- Keil 工程加入 SPI、misc、delay 文件和必要头文件搜索路径。
