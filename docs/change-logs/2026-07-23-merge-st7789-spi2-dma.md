# 合并 ST7789 SPI2 DMA

日期：2026-07-23

## 修改目标

将 Codex worktree `a538e81` 中已经完成的 DMA 版本同步回旧工程目录。
本次合并以代码状态对齐为目标，保留旧目录中已有的未跟踪 GIF 素材，
不覆盖与本次同步无关的本地文件。

## 修改前行为

旧目录停留在 `ab47845`。ST7789 像素数据仍主要通过同步 SPI 字节流发送，
动画差分刷新在主循环内完成整段解析和传输。Keil 工程未把
`stm32f10x_dma.c` 加入当前目标，文档和代码中也未体现 SPI2 TX DMA
已经接入。

## 修改后行为

旧目录同步到当前 Codex worktree 的 DMA 实现：

- ST7789 初始化、命令和地址窗口继续使用同步 SPI 字节发送。
- 清屏、矩形填充、完整帧和 GIF 差分像素流改为 SPI2 TX DMA 发送。
- SPI2 TX 使用 DMA1 Channel5，并通过 DMA 完成中断释放发送状态。
- ST7789 动画差分刷新改为异步状态机推进，支持双行 DMA 缓冲和错误恢复。
- 同步 Codex worktree 中已有的 USART1 TX DMA 相关改动和工程文件引用。

## 逻辑变化范围

本次合并直接同步 `ab47845..a538e81` 的功能差异：

- `bsp_st7789.c/.h` 增加 SPI2 TX DMA 初始化、DMA 状态、双行缓冲、
  同步 DMA 发送封装、异步差分任务接口和 DMA1 Channel5 中断处理。
- `app_st7789_anim.c` 改为调用异步差分任务，只有完整差分传输成功后才推进帧索引。
- `Project/led.uvprojx` 加入 `stm32f10x_dma.c`，并同步 USART1 DMA 相关文件引用。
- `SYSTEM/usart/usart.c/.h` 和 `User/main.c` 同步当前 worktree 的 USART1 TX DMA 改动。
- 追加当前 worktree 中已有的 2026-07-21/2026-07-22 DMA 变更记录。

## 接口与兼容性

ST7789 外部绘图接口保持兼容，并新增异步差分任务状态接口。
SPI2 引脚和 ST7789 接线不变。USART1 发送接口增加 DMA 发送能力。
Keil 工程需要编译 `Libraries/src/stm32f10x_dma.c`。
