# STM32F103 SPI OLED GIF 动画显示任务说明

## 0. 给 Codex 的总要求

你现在接手我的 STM32F103C8T6 工程。

请先阅读工程目录和现有代码结构，不要一上来大改整个项目。
本任务目标是：在现有裸机工程中新增 **SPI OLED 显示 GIF 动画** 功能。

注意：
STM32 不直接播放 `.gif` 文件。
GIF 必须在电脑端预处理成多帧 OLED 位图数组，STM32 只负责按帧刷新 OLED。

## 4. 推荐接线

请优先使用 SPI2，避免和我之前项目里 PA5、PA6、PA7 的交通灯引脚冲突。

推荐接线：

```text
OLED SCK / D0 / SCL     -> PB13
OLED MOSI / D1 / SDA   -> PB15
OLED CS                -> PB12
OLED DC                -> PB14
OLED RST / RES         -> PB10
OLED VCC               -> 3.3V
OLED GND               -> GND
```

说明：

```text
OLED 不需要 MISO
所有模块必须共地
VCC 优先接 3.3V
如果模块标注支持 3.3V/5V，也优先使用 3.3V
```

请在文档里写清楚每个引脚的作用：

```text
SCK：SPI 时钟
MOSI：SPI 数据输出
CS：片选
DC：命令/数据选择
RST：OLED 复位
VCC：电源
GND：地
```

## 6. SPI OLED 驱动层要求

请实现这些函数：

```c
void OLED_SPI_Init(void);
void OLED_SPI_WriteByte(uint8_t data);

void OLED_WriteCmd(uint8_t cmd);
void OLED_WriteData(uint8_t data);

void OLED_Reset(void);
void OLED_Init(void);
void OLED_Clear(void);
void OLED_SetPos(uint8_t page, uint8_t col);

void OLED_ShowImage128x64(const uint8_t *image);
```

### 6.1 GPIO 初始化要求

请初始化：

```text
PB13 -> SPI2_SCK
PB15 -> SPI2_MOSI
PB12 -> OLED_CS
PB14 -> OLED_DC
PB10 -> OLED_RST
```

要求：

```text
使用 STM32F10x 标准外设库
打开 GPIOB 时钟
打开 SPI2 时钟
SCK/MOSI 配置为复用推挽输出
CS/DC/RST 配置为普通推挽输出
```

### 6.2 SPI 初始化要求

使用硬件 SPI2。

请设置：

```text
主机模式
单向发送即可
8位数据
MSB first
合适的 SPI Mode
合适的分频系数
软件管理 NSS
```

请给关键配置加中文注释，尤其是：

```text
为什么是主机模式
为什么 OLED 不需要 MISO
为什么用软件控制 CS
为什么使用 8 位数据
```

### 6.3 OLED 初始化要求

按 SSD1306 128x64 SPI OLED 初始化。

要求：

```text
先复位 OLED
再发送初始化命令
初始化后清屏
```

允许在初始化阶段使用必要的短延时，例如 RST 复位延时。
但不要在动画播放任务中使用长时间 delay。

### 6.4 显示图片要求

`OLED_ShowImage128x64()` 要能显示一整张 128x64 黑白图片。

SSD1306 单色 128x64 全屏数据大小：

```text
128 * 64 / 8 = 1024 字节
```

也就是：

```c
#define OLED_WIDTH       128
#define OLED_HEIGHT      64
#define OLED_FRAME_SIZE  1024
```

图片数据格式按 SSD1306 页寻址方式：

```text
8 页
每页 128 字节
每个字节表示纵向 8 个像素
总共 8 * 128 = 1024 字节
```

## 7. 动画应用层要求

请实现：

```c
void App_Anim_Init(void);
void App_Anim_Task(void);
```

### 7.1 非阻塞播放要求

必须使用 `Timing_GetTick()` 做非阻塞定时。
不要在 `App_Anim_Task()` 里使用：

```c
delay_ms(100);
```

推荐逻辑：

```c
void App_Anim_Task(void)
{
    static uint32_t last_tick = 0;
    static uint8_t frame_index = 0;

    if (Timing_GetTick() - last_tick >= ANIM_FRAME_INTERVAL_MS)
    {
        last_tick = Timing_GetTick();

        OLED_ShowImage128x64(anim_frames[frame_index]);

        frame_index++;

        if (frame_index >= ANIM_FRAME_COUNT)
        {
            frame_index = 0;
        }
    }
}
```

### 7.2 宏定义要求

请用宏统一管理：

```c
#define ANIM_FRAME_WIDTH        128
#define ANIM_FRAME_HEIGHT       64
#define ANIM_FRAME_SIZE         1024
#define ANIM_FRAME_COUNT        xx
#define ANIM_FRAME_INTERVAL_MS  100
```

### 7.3 播放效果要求

初始阶段可以先用两张测试图片来回切换。
不要一开始就塞真实 GIF 大数组。

阶段顺序必须是：

```text
先单张图
再两张图切换
再多帧动画
```

### 8.3 输出文件要求

```text

```

推荐头文件格式：

```c

#include <stdint.h>

#define ANIM_FRAME_WIDTH        128
#define ANIM_FRAME_HEIGHT       64
#define ANIM_FRAME_SIZE         1024
#define ANIM_FRAME_COUNT        xx

#endif
```

推荐 C 文件格式：

```c
#include "anim_frames.h"

const uint8_t anim_frames[ANIM_FRAME_COUNT][ANIM_FRAME_SIZE] = {
    {
        // frame 0
    },
    {
        // frame 1
    },
};
```

如果你决定只生成 `.h` 文件，也可以，但必须解释原因。

### 8.4 Python 脚本依赖

## 9. Flash 和 RAM 限制说明

请在文档中明确说明容量限制。

128x64 单色 OLED：

```text
1 帧 = 1024 字节 ≈ 1KB
10 帧 ≈ 10KB
20 帧 ≈ 20KB
30 帧 ≈ 30KB
60 帧 ≈ 60KB
```

STM32F103C8T6 资源有限：

```text
Flash 标称通常是 64KB
RAM 通常是 20KB
```

所以初期建议：

```text
帧数：8~20 帧
帧率：5~12 FPS
分辨率：128x64
颜色：黑白
```

要求：

```text
动画数组必须放在 Flash，不要放进 RAM
不要 malloc
不要运行时动态加载图片
不要在 STM32 端解析 GIF
```

## 12. 排错清单要求

文档中必须包含排错顺序。

### 12.1 屏幕完全不亮

按顺序检查：

```text
VCC 是否接 3.3V
GND 是否共地
RST 是否接对
CS 是否接对
DC 是否接对
SCK/MOSI 是否接反
SPI2 时钟是否打开
GPIOB 时钟是否打开
OLED 初始化命令是否发送
```

### 12.2 屏幕亮但不显示

检查：

```text
DC 命令/数据电平是否反了
CS 是否一直有效
SPI 模式是否错误
初始化命令是否适合 SSD1306
是否使用了 SH1106 但没有处理列偏移
```

### 12.3 图像错位

检查：

```text
取模方向是否正确
页地址是否正确
列地址是否正确
SSD1306 / SH1106 是否有列偏移差异
```

### 12.4 图像上下反了或左右反了

检查：

```text
SSD1306 segment remap 命令
COM scan direction 命令
Python 转换脚本的像素遍历顺序
```

### 12.5 动画卡顿

检查：

```text
是否使用 delay_ms 阻塞
是否每帧刷新太频繁
SPI 分频是否太低
帧数是否过多
主循环里是否还有其他阻塞任务
```

### 12.6 编译 Flash 超限

检查：

```text
GIF 帧数是否过多
是否没有使用 --max-frames
是否把数组重复定义在多个文件
是否把动画数组放进 RAM
是否启用了太多测试图片
```
